# St. Michael & All Angels Parish — Website

A modern, responsive single-page parish website built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🌟 Key Sections & Features

1. **Top Announcement & Microbar**: Address, office phone, livestream status pill, and online giving link.
2. **Sticky Navigation Bar**: Responsive navigation with mobile drawer menu and quick mass times CTA.
3. **Hero Header**:
   - Church name, est. 1948, parish mission motto
   - "Join Us This Sunday" quick schedule pill
   - Calls to action: Mass Times, About Us, Directions & Map
   - Key parish statistics (75+ Years, 1,400+ Families, 5 Sunday Masses)
4. **Mass & Service Schedule**:
   - Filterable tabs: Complete Schedule, Weekend Masses, Daily Mass, Confession, Adoration
   - Bilingual mass indicators (English, Spanish, Latin chants)
   - Holy Days of Obligation information & priest contacts
5. **Upcoming Events**:
   - Filterable event categories (Community, Liturgy & Music, Outreach & Charity, Faith Formation, Youth)
   - Interactive modal view with full details
   - Interactive "Save Date / RSVP" action with toast feedback
   - Weekly Parish Bulletin download button
6. **About Us & Parish Heritage**:
   - Pastor's welcome letter and profile
   - 4 Core Pillars of parish life
   - Parish leadership & clergy roster
7. **Ministries & Community Outreach**:
   - Ministry overview cards with leaders and participant counts
   - Interactive "Volunteer & Ministry Inquiry" modal form
8. **Contact & Location**:
   - Parish office hours, address, phone numbers, emergency sacramental line
   - **Interactive Campus & Sanctuary Map Placeholder** with Google Maps directions link and parking notice
   - **Prayer Request & Contact Form** with category selection and submission feedback
9. **Footer & Stewardship**:
   - Online giving callout
   - Weekend mass schedule recap
   - Sacramental emergency 24/7 hotline

---

## 🚀 Running the Project with Node.js & Vite

When you have Node.js installed on your computer:

```bash
# 1. Install dependencies
npm install

# 2. Start the Vite local development server
npm run dev

# 3. Build for production deployment
npm run build
```
